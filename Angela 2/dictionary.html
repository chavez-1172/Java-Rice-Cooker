Java Dictionary

Important Terms in Java and Their Definition

A handy dictionary for Java that you can use when you encounter difficult and unusual terms.

1. Class

  • An extensible program-code-template or blueprint for creating objects, defining their initial state (field variables) and behaviors (methods).

    • 2. Compiler

  • A software utility that translates high-level human-readable Java source code (.java) into intermediate machine-executable Bytecode (.class).

    • 3. Concatenation

  • The process of joining two or more strings together end-to-end to form a single continuous string sequence.

    • 4. Constructor

  • A special block of code resembling a method that shares the exact class name and executes automatically to initialize an object when instantiated via the 'new' keyword.

    • 5. Data Type

  • A classification that dictates the type of data a variable can store, the set of operations that can be performed on it, and its memory allocation.

    • 6. Encapsulation

  • An Object-Oriented Programming (OOP) principle of bundling state data and methods together within a single class while restricting direct external access to variable fields via private access modifiers.

    • 7. Exception

  • An event or condition that disrupts the normal execution flow of a program during runtime when an error occurs.

    • 8. IDE (Integrated Development Environment)

  • A comprehensive software suite providing developer tools such as a source code editor, build automation, debugger, and compiler integration in one GUI.

    • 9. Import

  • A keyword used to make classes or entire packages located in other libraries or folders available within the current source file.

    • 10. JDK (Java Development Kit)

  • A complete software package containing the Java Runtime Environment (JRE), Java Virtual Machine (JVM), compiler (javac), libraries, and development tools required to build Java applications.

    • 11. Method

  • A programmed sequence of executable statements grouped together under a unique identifier to perform a specific task or operation when invoked.

    • 12. Null

  • A built-in literal value representing the absence of an object reference or an uninitialized reference variable.

    • 13. Package

  • A namespace mechanism used to group related classes, interfaces, and sub-packages together to prevent naming conflicts and organize code architecture.

    • 14. Parameter / Argument

  • A parameter is a variable declaration in a method definition; an argument is the actual value passed into that parameter when the method is invoked.

    • 15. Recursion

  • A programming technique in which a method calls itself directly or indirectly to solve smaller instances of the same computational problem until reaching a base condition.

    • 16. Syntax

  • The strict set of structural rules, grammar, and structural format that governs how valid code must be written in a programming language.

    • 17. Variable

  • A named storage location in system memory reserved to hold a value of a specific data type during program execution.
