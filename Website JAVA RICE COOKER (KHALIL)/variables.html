Java Programming Language

Data Types & Variables

Think of a variable as a labeled storage box in memory used to store data. In Java, you must declare what kind of data fits inside the box (its data type).

  • For instance, a dog is an animal, a banana is a fruit, and a cucumber is a vegetable.
  • The same logic applies to variables and data types. Each data type can only accept a value that fits into their category.

1. Primitive Types (Direct Values)

These types of variables hold single, basic pieces of data.

int (Integers): Holds whole numbers only as values.

Example: int watermelonSlices = 8;

double (Decimals): Holds numbers that contain decimals as values.

Example: double catWeight = 4.5;

char (Single Character): One letter or symbol enclosed in 'single quotes'.

Example: char rank = 'S';

boolean (True/False): A simple on/off or true/false switch.

Example: boolean amlHungry = true;

Sample Code

class sample {
    public static void main(String[] args) {
        String mimmingName = "Momo";
        int age = 3;
        double weight = 4.2;
        boolean lovesFood = true;

        System.out.println(mimmingName + " is " + age + " years old.");
        System.out.println("Loves food? " + lovesFood);
    }
}

OUTPUT:

Momo is 3 years old.
Loves food? true

2. Reference Types (Complex Data)

These hold complex data or points to bigger items in memory.

String: Text written in "double quotes".

Example: String mimmingName = "Momo";

Arrays: A grouped list of items of the same type.

Example: String treats[] = {"Fish", "Chicken", "Milk"};

We will be more in-depth with Arrays in another lesson. For now, you should only know what it is for.

In the code example, String concatenation connected the variables and text together into a single line.

The + operator combines these values with the text strings. Note that the additional text you want to put must be placed inside double quotation marks ("") so that the compiler recognizes them as texts.
